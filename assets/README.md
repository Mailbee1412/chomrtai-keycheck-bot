# assets

โฟลเดอร์นี้ไว้สำหรับรูปประกอบของร้าน เช่น **QR รับเงิน** (`shop-qr.png`)

> ⚠️ ไฟล์รูป (`*.png`) **ไม่ถูก commit ขึ้น GitHub** เพราะเป็น QR ของร้านจริง
> แต่โครงสร้างโฟลเดอร์นี้ถูกเก็บไว้ คนที่ clone ไปจึงรู้ว่าต้องวางรูปตรงไหน

## วิธีใช้

1. ก๊อปรูป QR ของคุณมาวางที่ `assets/shop-qr.png` (สร้างไฟล์ได้เลยถ้ายังไม่มี)
2. ตั้งค่า path ใน `.env`

```env
SHOP_QR_IMAGE_PATH=assets/shop-qr.png
```

3. รีสตาร์ทบอท — รูปจะถูกแนบในห้องออเดอร์อัตโนมัติ

> path สัมพัทธ์จะถูกหาจากโฟลเดอร์ที่รันบอทก่อน แล้วค่อยหาจากโฟลเดอร์โปรเจกต์
> ถ้าเปิดบอทจากที่อื่นแล้วยังไม่เจอ ให้ใส่ **absolute path** แทน

## ถ้าจะเอาไปรันบนเซิร์ฟ (VPS / Docker / Panel)

ไฟล์รูปจะไม่ติดมากับ `git pull` เพราะถูก ignore — ต้องทำเอง 2 ทางเลือก:

**ทางเลือก A (แนะนำ) — เก็บรูปไว้นอกโฟลเดอร์รีโป**

วางรูปไว้ในโฟลเดอร์ที่อยู่นอกรีโป แล้วชี้ path แบบ absolute

```env
# Linux
SHOP_QR_IMAGE_PATH=/opt/chomrtai-assets/shop-qr.png
# Windows
SHOP_QR_IMAGE_PATH=C:\chomrtai-assets\shop-qr.png
```

ข้อดี: `git pull` / ลบรีโปทิ้งแล้ว clone ใหม่ รูปยังอยู่

**ทางเลือก B — เก็บในรีโปเหมือนเดิม**

โฟลเดอร์ `assets/` อยู่ในรีโบอยู่แล้ว แค่สร้างโฟลเดอร์แล้วก๊อปรูปมาวางก่อนรัน

> ถ้าบอทหาไฟล์ไม่เจอ จะขึ้นคำเตือนใน log ว่า
> `[shop] ไม่พบไฟล์รูป QR: ...` และห้องออเดอร์จะไม่แนบรูป (บอทยังทำงานต่อ ไม่พัง)
